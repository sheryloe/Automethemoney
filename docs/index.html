왜 GitHub Pages 방식이 유리한가

빠른 전달

페이지 목적을 서비스 설명에 고정해 방문자가 핵심 내용을 바로 이해합니다.

안정적 운영

정적 파일 중심으로 구성해 운영 복잡도를 낮추고 장애 요인을 줄입니다.

쉬운 갱신

`docs/index.html`만 수정하면 최신 소개 문구와 UI를 빠르게 반영할 수 있습니다.
