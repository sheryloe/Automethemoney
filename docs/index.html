실전 구현 포트폴리오

이 프로젝트는 GitHub-hosted Actions로 주기 실행하고, Supabase에 상태를 기록하며, Vercel에서 운영 화면을 제공하는 자동화 서비스 구현 사례입니다.

핵심 목표 무중단 자동 사이클
스케줄 실행 GitHub-hosted Actions
상태/성과 저장 Supabase 테이블
운영 콘솔 Vercel 웹 화면
포트폴리오 핵심: 구조를 분리해 운영 안정성과 추적 가능성을 확보

무엇을 만들었는가

자동 실행 파이프라인

정해진 주기에 배치를 실행해 모델 계산과 상태 갱신을 반복합니다.

상태/이력 관리

하트비트, 모델 설정, 포지션, 일일 성과를 테이블로 분리해 저장합니다.

운영 확인 화면

서비스 운영에 필요한 핵심 상태를 웹 화면에서 바로 점검할 수 있게 구성했습니다.

어떻게 구성했는가

01

GitHub-hosted Actions 스케줄로 사이클을 트리거합니다.

02

배치 스크립트가 모델 상태와 포지션 데이터를 계산/갱신합니다.

03

결과를 Supabase에 기록해 이력과 검증 근거를 남깁니다.

04

Vercel 화면에서 현재 상태를 조회하고 운영 판단에 활용합니다.

이 구조를 그대로 재현하면 자동 실행 + 기록 + 조회 흐름을 일관되게 구현할 수 있습니다.
