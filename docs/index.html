Automethemoney Brochure
Google Stitch UI API 연동 없음

홍보용 브로셔를
가장 안정적으로 운영하는 방식

Automethemoney는 GitHub Pages의 `docs` 폴더만 사용합니다. Google Stitch로 만든 UI를 정적 HTML/CSS로 반영하고, 백엔드/API 없이 빠르게 공개 페이지를 운영합니다.

사이트 유형 브로셔 전용
배포 방식 GitHub Pages
콘텐츠 위치 `docs/index.html`
자동화 방식 WSL cron
운영 기준: 정적 파일만 유지, 액션/서버 미사용

핵심 가치

빠른 수정

문구/섹션/디자인 변경을 `index.html` 한 파일 기준으로 즉시 반영합니다.

낮은 장애 위험

외부 API, 인증, 서버 장애 요소를 제거해 노출 페이지 안정성을 높입니다.

운영 단순화

배포 경로를 `main + /docs`로 고정해 유지보수 비용을 최소화합니다.

Google Stitch 반영 플로우

01

Google Stitch에서 브로셔 UI 생성

02

정적 HTML/CSS 형태로 결과 정리

03

`docs/index.html`에 디자인/카피 반영

04

`git push` 후 GitHub Pages 자동 공개

현재 구성은 홍보용에 최적화되어 있으며, API 연동 없이도 디자인 전달력이 유지됩니다.

운영 규칙

콘텐츠 범위

랜딩 소개, 가치 제안, 사용 흐름, CTA 중심 구성만 유지합니다.

기술 범위

HTML/CSS/소량 JS만 사용하고, 프레임워크/런타임 의존을 두지 않습니다.

자동화 범위

GitHub Actions 대신 WSL cron으로 정적 변경 커밋/푸시만 수행합니다.

다음 수정도 동일 방식으로 진행: Stitch UI 생성 → `docs/index.html` 반영 → 배포 저장소 열기
